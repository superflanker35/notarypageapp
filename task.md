**Необходимо создать страницу записи к нотариусу.**

1) Когда пользователь заходит на главную страницу, проверяется есть ли у него cookie с id. Если нет, нужно назначить и на беке записать в базу id пользователя и время его создания.

2) На главной странице пользователь может ввести имя, фамилию, почту, выбрать дату с помощью всплывающего календаря, и из списка предустановленного один из вариантов:
- доверенность
- наследство
- справка

Эти данные на беке надо сохранить в таблицу с записями, и указать id пользователя, который создал запись.

3) при сохранении надо с помощью observer в laravel отправить письмо с данными которые пользователь ввел ему на почту в письме.  

4) При повторном открытии страницы, надо проверить, есть ли у пользователя записи, которые он ранее создал (по id из cookie). И если есть, то вывести список записей. 

Делать надо  на laravel для бека, и на vue для фронта. Конкретная реализация дальнейшая на ваше усмотрение.
